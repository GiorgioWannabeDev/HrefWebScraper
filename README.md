# Web Page Link Scraper

A lightweight Python script to extract and display all hyperlinks (`href` attributes) from any web page.

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/GiorgioWannabeDev/HrefWebScraper
   cd HrefWebScraper

2. Install dependencies:
    ```bash
    pip install -r requirements.txt

3. Run the script
    ```bash
    python project.py
